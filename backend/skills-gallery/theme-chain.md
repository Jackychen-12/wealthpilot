# 题材产业链拆解

题材热的时候，板块里的股票一起涨；但真正赚到钱的，往往只是产业链上最难扩产、最难被替换的那一两个环节。这个方法不预测题材还能涨多久，只回答：钱最后会流到哪个环节，哪些公司是真的在那个环节上。

- industry: 先用 get_concept_stocks 拿到这个题材对应的概念板块和成分股（板块名对不上就用 get_concept_boards 找最接近的）。然后把产业链从下游往上游拆开：终端需求 → 系统或整机 → 核心部件 → 设备 → 材料 → 封装测试或基础设施，每个环节写清楚做什么、板块里有哪几家公司。接着判断哪个环节最难替代：供应商少不少、客户认证周期长不长、扩产要多久、技术或纯度门槛高不高——每一条都要有来源，查不到就用 web_search 找公告、行业报道或政策原文，仍然查不到就写"没有查到依据"。不要给环节打综合分数，用证据和道理说清楚先后。
- fundamental: 对最关键环节上的两到三家公司，用 get_business_segments 看主营构成：和这个题材直接相关的产品收入占多少、毛利率多少。占比很低的要明说是"沾边"。再用 get_financial_indicators 看最近几期的营收和利润有没有已经体现出来——订单和景气如果是真的，迟早要进报表。
- expectation: 用 get_stock_news 和 web_search 找这个题材最近的催化（政策、大订单、技术突破、涨价），写明来源和日期；同时找反面的消息：产能过剩、价格战、技术路线被替代、大客户自研。网上的说法没有核实过，互相矛盾的地方如实写矛盾。

「真受益与沾边」这一节用一张小表：公司、所在环节、相关收入占比（引用主营构成）、是真受益还是沾边、依据。没有主营数据支撑的，只能写"未核实"。

「待验证」写成之后能用财报或公告核对的条件，例如"某公司下一期该产品收入占比超过三成"。
