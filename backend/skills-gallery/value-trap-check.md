# 低估值陷阱检查

低估值有两种来历：市场错了，或者盈利要掉了。这个方法只回答是哪一种。

- fundamental: 取多期财务指标。重点看三件事：净利润和扣非净利润的同比是不是在逐期变差；毛利率、净利率是不是在往下走；经营现金流是不是明显少于净利润。再用 read_latest_report 读管理层对业绩变动的解释和风险提示，看公司自己有没有承认需求或价格在走弱。
- valuation: 取 PE / PB 历史分位和同行对比。说清楚这个"便宜"是相对自己的历史，还是相对同行，还是两者都是。PE 低而 PB 不低、或者 PS 分位远高于 PE 分位，都要点出来——这通常说明利润处在高点。
- industry: 查同行业公司的估值和当日表现，以及这家公司近期的公告。整个行业都便宜，和只有它便宜，是两回事。

「陷阱信号」一节逐条列出命中了哪些：盈利逐期下滑、利润率收窄、现金流跟不上利润、只有它比同行便宜、近期有减持或问询类公告。一条都没命中也要明说。
