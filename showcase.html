两条命令，跑起来 Two Commands to Get Started

克隆 → make setup → 终端直接对话。或启动完整前后端。 Clone → make setup → chat in terminal. Or launch the full stack.

$ git clone github.com/Jackychen-12/wealthpilot && cd wealthpilot
$ make setup         # 安装依赖 + 生成 .env
$ vim backend/.env    # 填入 API Key
$ make chat          # 终端 AI 对话
$ make dev           # 或启动完整前后端
